# Two-term demo scenario

This folder contains fictional PDFs for the Muni demo. Upload the six PDFs in any order to show how Muni compares award, bill, housing, study-abroad, and payment-plan documents across Fall 2026 and Spring 2027.

The scenario intentionally includes a scholarship mismatch, a credit shortfall, an unpaid balance, a housing difference, a possible double charge, and upcoming deadlines. The Fall term is fully covered and should not produce a coverage finding.

All documents are synthetic and contain no real student data.
